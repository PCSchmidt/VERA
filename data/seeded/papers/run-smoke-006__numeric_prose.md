## Abstract

We report a small, automated attempt to improve TreeHFD, a method that decomposes an xgboost model into main effects and second-order interactions [R1], where the xgboost model is trained as in [R2]. The baseline was first reproduced against the paper's reference values within the registered tolerance (gate verdict True). Two ideas out of three generated by the loop were then run on two datasets (Analytical, Airfoil) with 3 seeds, using xgboost with 100 trees, held-out data, and Residual MSE (%) (lower is better) as the metric. No idea beat the baseline on every dataset. Depth-variable tuning improved Analytical (2.41 vs 2.79) but worsened Airfoil (5.14 vs 4.73). Refit intercept residual degraded both datasets, catastrophically on Airfoil. This is a negative result from a crude loop; we state plainly what it did and did not establish.

## Method

The loop first reproduced the TreeHFD baseline [R1] applied to an xgboost model [R2]. The reproduction was checked against the paper's reference values and passed within the registered tolerance (gate verdict True). The baseline residual MSE (%) under the paper's convention (in-sample) was 0.570 on Analytical and 1.52 on Airfoil; the results table below shows held-out values, which are higher.

Three ideas were generated; two were run on the subset:

- **C3: Refit intercept residual.** After TreeHFD's fit, compute the residual r = model(X) − sum(components) on training data. Add the mean residual to the intercept, and optionally refit the largest interaction components (via treehfd refit or ridge on their variables) to the residual. Each refit maps only its own component's variables to output, keeping additivity while shrinking held-out residual MSE.
- **C2: Depth-variable tuning.** Sweep depth_variable over several values (e.g., 2, 3, 4, 5) on training data, evaluate held-out Residual MSE for each, and select the best. Deeper variable selection changes which splits define main effects, often reducing the unexplained residual. Only the chosen configuration is used for the final fit; all components remain functions of their own variables.

All evaluations used 3 seeds, xgboost with 100 trees, held-out data, and Residual MSE (%), lower is better, with runtime in seconds also recorded.

## Results

No idea beat the baseline on every dataset. The results are:

Results from a research-loop run on the TreeHFD problem (mean ± std over 3 seeds). ↓ = lower is better; ↑ = higher is better.

| Method | Analytical · Residual MSE (%) ↓ | Analytical · Runtime (s) ↓ | Airfoil · Residual MSE (%) ↓ | Airfoil · Runtime (s) ↓ |
|---|---|---|---|---|
| TreeHFD (baseline) | 2.79 ± 0.32 | 27.2 ± 0.97 | 4.73 ± 0.11 | 3.49 ± 0.094 |
| C3: Refit intercept residual | 31.3 ± 2.6 | 30.9 ± 0.48 | 36581 ± 1750 | 3.77 ± 0.14 |
| C2: Depth-variable tuning | 2.41 ± 0.16 | 52.2 ± 3.1 | 5.15 ± 0.66 | 10.2 ± 0.63 |

C2 (depth-variable tuning) improved held-out Residual MSE on Analytical (2.41 ± 0.16 vs the baseline's 2.79 ± 0.32) but worsened it on Airfoil (5.15 ± 0.66 vs 4.73 ± 0.11), at roughly triple the baseline runtime on Airfoil (10.2 ± 0.63 vs 3.49 ± 0.094). C3 (refit intercept residual) was worse on both datasets: 31.3 ± 2.6 on Analytical and 36581 ± 1750 on Airfoil, a very large degradation on Airfoil despite only modestly higher runtime. The third generated idea was not run.

## Limitations

This was a crude loop, and the conclusions are correspondingly narrow:

- Only 3 seeds were used, so the seed-level variation is not well characterized.
- Only two datasets (Analytical, Airfoil) were evaluated; behavior on other data is unknown.
- Only one model configuration was used: xgboost with 100 trees.
- Three ideas were generated and only two were run, both produced and implemented by a language model; implementation errors or poor hyperparameter choices cannot be ruled out, particularly for C3, whose failure mode (an enormous Airfoil residual) was not diagnosed further.
- The loop did not establish why C2 helps on one dataset and hurts on the other, nor whether C3 could be repaired with different refitting choices.
- The gate check verified the baseline against the paper's reference values within tolerance, but the held-out numbers reported here are not directly comparable to the paper's in-sample convention.

The honest summary: neither idea beat the baseline on every dataset, and this attempt should be treated as a negative result, not evidence that TreeHFD cannot be improved.
